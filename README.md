## Введение

Цель данного исследования — разработать практические рекомендации для повышения эффективности бизнеса маркетплейса на основе анализа продаж.

Анализ проводится по двум направлениям:

1. **Оптимизация ассортиментной матрицы**:
   - выявление товаров для вывода из ассортимента
   - определение позиций с потенциалом роста
   - поиск возможностей для увеличения маржинальности

2. **Работа с клиентской базой**:
   - выявление сегментов для удержания и реактивации
   - поиск точек роста LTV (Lifetime Value)
   - развитие кросс-продаж

**Период анализа**: 2025 год (последний полный год данных)  
**Методология**: ABC-анализ (по выручке и количеству), XYZ-анализ (по стабильности спроса), матрица ABC-XYZ, RFM-сегментация клиентов  

> ⚠️ *Примечание по маржинальности*: в данных отсутствует себестоимость товаров, поэтому маржинальность напрямую не рассчитывается. Рекомендации в этой части носят гипотезный характер (изменение цен или закупочных условий).

**Источник данных**: ETL-пайплайн [`marketplace-data-pipeline`](https://github.com/Liza-VETA1104/marketplace-data-pipeline), агрегированные данные за 2025 год.

# 1. Оптимизация ассортиментной матрицы

## 1.1. Методология

Анализ построен на классическом ABC-XYZ-подходе:

- **ABC-анализ** (по выручке и по количеству продаж) — выделение групп товаров по вкладу в результат (правило Парето 80/20)
- **XYZ-анализ** (стабильность продаж) — коэффициент вариации (CV) дневных продаж:
- **Матрица ABC-XYZ** — 3×3, показывающая пересечение двух классификаций

## XYZ-анализ

В ходе анализа было выявлено, что коэффициент вариации (CV) для большинства товаров превышает 25%, что делает применение классических порогов XYZ некорректным (все товары попадали бы в категорию Z).

Использовано квантильное разделение, поэтому категории XYZ отражают относительную, а не абсолютную стабильность спроса:
- X — нижние 33.3% по CV (наиболее стабильные товары)
- Y — средние 33.3%
- Z — верхние 33.3% (наиболее нестабильные товары)

При работе с реальными данными без выраженной вариативности целесообразно использовать стандартные пороги:
- X — CV < 10%
- Y — 10% ≤ CV < 25%
- Z — CV ≥ 25%

### Ключевые инсайты

- **Лидеры (A по обеим метрикам)** – 21 739 товаров формируют основу выручки и продаж.  
- **«Золотые» товары (AAX)** – 10 091: высокая выручка, высокий спрос, стабильность. Зона стратегического контроля (запасы, цена, промо, доступность). 
- **Кандидаты на вывод (CCZ)** – 1 248: низкая выручка, низкий спрос, нестабильность. Поэтапная очистка ассортимента, чтобы избежать потерю редких, но важных продаж.

### Ожидаемые результаты оптимизации

- Снижение неэффективного ассортимента

- Высвобождение складских мощностей  
- Потенциальный рост выручки  
- Повышение рентабельности за счёт фокуса на ключевых категориях (AX, AAX)
