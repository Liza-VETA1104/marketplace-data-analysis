## Введение

Цель данного исследования — разработать практические рекомендации для повышения эффективности бизнеса маркетплейса на основе анализа продаж.

Анализ проводится по двум направлениям:

1. **Оптимизация ассортиментной матрицы**:
   - выявление товаров для вывода из ассортимента
   - определение позиций с потенциалом роста
   - поиск возможностей для увеличения маржинальности

2. **Работа с клиентской базой**:
   - выявление сегментов для удержания и реактивации
   - поиск точек роста LTV (Lifetime Value)
   - развитие кросс-продаж

**Период анализа**: 2025 год (последний полный год данных)  
**Методология**: ABC-анализ (по выручке), XYZ-анализ (по стабильности спроса), матрица ABC-XYZ, RFM-сегментация клиентов  

> ⚠️ *Примечание по маржинальности*: в данных отсутствует себестоимость товаров, поэтому маржинальность напрямую не рассчитывается. Рекомендации в этой части носят гипотезный характер (изменение цен или закупочных условий).

**Источник данных**: ETL-пайплайн [`marketplace-data-pipeline`](https://github.com/Liza-VETA1104/marketplace-data-pipeline)

### Методика

- **ABC** — по суммарной выручке (`total_price`)  
- **XYZ** — по стабильности спроса (коэффициент вариации месячных продаж)  

**Границы XYZ (адаптированы под данные):**

- **X** — CV ≤ 45%  
- **Y** — 45% < CV ≤ 75%  
- **Z** — CV > 75%  

Средний CV по всем товарам: **67.0%**

### Общие выводы

Распределение ABC‑XYZ показывает **отсутствие ярко выраженного ядра сверхстабильных товаров** (доля X — всего 5.8%). Основной вклад в выручку распределён между большим количеством SKU (группа AY — 36.8% ассортимента), что характерно для широкого ассортимента маркетплейса.

**Основные рекомендации:**

1. **Фокус на группу AY** — именно здесь сосредоточена основная выручка. Необходимо усилить прогнозирование и контроль запасов.  
2. **AZ** — важные, но нестабильные позиции. Требуется анализ причин колебаний (сезонность, перебои поставок).  
3. **CZ** — чёткий сигнал к чистке ассортимента: распродажа остатков, остановка закупок.  
4. **Стабильных товаров (X) очень мало** — это ограничивает возможность точного долгосрочного планирования и требует более частого пересмотра прогнозов.

### Ожидаемые результаты оптимизации

- Снижение неэффективного ассортимента  
- Рост оборачиваемости запасов
