## Введение

Цель данного исследования — разработать практические рекомендации для повышения эффективности бизнеса маркетплейса на основе анализа продаж.

Анализ проводится по двум направлениям:

1. **Оптимизация ассортиментной матрицы**:
   - выявление товаров для вывода из ассортимента
   - определение позиций с потенциалом роста
   - поиск возможностей для увеличения маржинальности

2. **Работа с клиентской базой**:
   - выявление сегментов для удержания и реактивации
   - поиск точек роста LTV (Lifetime Value)
   - развитие кросс-продаж

**Период анализа**: 2025 год (последний полный год данных)  
**Методология**: ABC-анализ (по выручке и количеству), XYZ-анализ (по стабильности спроса), матрица ABC-XYZ, RFM-сегментация клиентов  

> ⚠️ *Примечание по маржинальности*: в данных отсутствует себестоимость товаров, поэтому маржинальность напрямую не рассчитывается. Рекомендации в этой части носят гипотезный характер (изменение цен или закупочных условий).

**Источник данных**: ETL-пайплайн [`marketplace-data-pipeline`](https://github.com/Liza-VETA1104/marketplace-data-pipeline), агрегированные данные за 2025 год.
